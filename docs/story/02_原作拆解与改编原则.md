# 02 原作拆解与改编原则

> 原作：《我的前任是逃犯》（没药花园整理，口述人阿林，共18章）。
> 本文先拆解原作中可用于游戏的素材，再给出改编原则与人名、地名对照表。

---

## 1. 一句话概括原作

一个习惯当"和事佬"的中年美籍华人，在一次租车纠纷中认识了一个自称富家千金的年轻女人。他和她恋爱、同居，帮她换汇。此后朋友的银行卡被冻，他顺着她的真名查到一宗网红跨国失踪案，又在搬家时翻到她"金融犯"男友的卷宗，发现对方涉及菲律宾绑架杀人案。随后他遭到她的假报案、恐吓和上门骚扰，最后听到了她为自己开脱的"新版本"。

## 2. 原作的核心主题（改编时必须保留）

| 主题 | 原作体现 | 游戏化方向 |
|---|---|---|
| **人人都在讲故事** | 晶晶的富家人设、狱中老刘的"大哥"人设、娜娜案的四个版本 | 谎言是可收集、可比对、可拆穿的"物件" |
| **核实胜于相信** | "我只看三样东西" | 三角印证系统（核心机制） |
| **操控与自我怀疑** | "真正喜欢我的人，都会站在我这一边"；"争到最后，甚至会让你开始怀疑，是不是自己哪里搞错了" | 玩家的「清醒度 / 自我怀疑」状态 |
| **灰色社区的沉默** | 无证房客逃跑、证人不肯作证、"他们不是不知道，而是害怕惹麻烦" | 证人信任与保护系统；社区声望 |
| **加害者也可以是受害者** | "一个人可以是某些事情的加害者，同时也可能是另外一个故事里的受害者" | 不提供简单的善恶结局 |

| **色字头上一把刀 / 沉没成本** | 主角明知不对仍留下；晶晶不愿从美梦中醒来 | 关系系统中的"欲望""沉没成本"倾向 |

## 5. 改编原则

### 原则一：虚构化处理（必须）
原作是**真实事件的口述纪实**，涉及至今下落不明的真实受害者、真实遇害者和正在司法程序中的真实嫌疑人。为此：
1. **全部人名、网名、外号改为虚构**（见第6节对照表）。原作中出现的具名人物（包括新闻人物）一律不进入游戏。
2. **地名虚构化**：美国城市改为虚构的「湾城」；菲律宾改为虚构岛国「南屿」，马尼拉改为「圣罗莎港」。
3. **新闻事件替换**：原作中借用的真实新闻（澳洲车祸、虚拟币案、明星恋爱长文）替换为游戏世界里的虚构新闻，保留"她把新闻拉进自己故事"的模式。
4. **受害者的结局保持未解**：失踪网红「鹿鸣」的下落在游戏里**不给出确定答案**。一是尊重原型案件仍未结案，二是"未解"本身是主题（家属的一线希望）。
5. 改编版权和原作授权需要项目方另行确认，本文只做创作设计。

### 原则二：玩家 = 主角，但不是复述者
玩家扮演主角「陈默」。原作的结果是**一条可能的路线**（"原作线"），玩家可以：
- 更早看穿（高清醒度路线），
- 陷得更深（结婚 → VAWA 陷阱），
- 做出原作主角拒绝的事（共谋路线，坏结局）。

### 原则三：硬节拍不变，体验可变
现实中不受主角控制的事件（老刘被捕、王丽报警、冻卡、遣返）是**硬节拍**，一定会发生。玩家影响的是：**知道多少、提前多久、谁站在你这边、谁因你受损**。

### 原则四：AI 负责"人"，剧本负责"事"
- 剧本 / storylet 决定**发生什么**。
- AI NPC 决定**每个人怎么说、怎么撒谎、怎么记住你**。
- 真相层（Canon）是 GM 唯一事实，LLM 不得改写。

### 原则五：不美化、不猎奇
- 绑架、杀人、诈骗园区一律在画面外，只通过文件和证词出现。
- 不提供任何现实可用的犯罪方法细节（洗钱、移民欺诈的具体操作）。
- 晴晴有复杂的成因（原生家庭、被灌输、沉没成本），但游戏不为她洗白；结局文本坚持原作立场："当拆穿一个谎言后，就要逃得远远的，不要心软。"

### 原则六：扩展而不篡改
新增支线遵循三条规则：
1. 以原作提到但未展开的人物或细节为种子（保姆、阿娟、经纪人、编剧房东、玄学女人、洗纹身……）。
2. 不新增与原作事实冲突的"真相"。凡是原作作者明确说"无法确认"的部分，游戏也保持多解。
3. 每条支线都必须回流主线（提供证据、证人、或制造代价）。

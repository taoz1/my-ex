# 03 改编总纲：世界观、核心体验与故事结构

## 1. 项目定位

- **工作标题**：《第四个版本》（备选：《和事佬》《湾城往事》《她说》）
- **类型**：AI NPC 驱动的都市开放世界 RPG，叙事加调查加社交
- **视角**：第三人称，或"手机加车载"的混合界面（大量信息通过手机 App 获得）
- **体量建议**：主线 15–20 小时，加支线和系统内容 15–25 小时
- **一句话（Logline）**：
  > 你是湾城华人圈里人人都找的"和事佬"。一场租车纠纷让你认识了一个自称富家千金的女孩。她的每一个故事都讲得天衣无缝，直到你的朋友们的银行卡一张接一张被冻结。

## 2. 体验支柱（Design Pillars）

1. **每个人都在讲故事**：所有 NPC 都有自己的版本；同一件事，不同的人、不同的听众、不同的时间，讲法都不一样。
2. **只信三样东西**：自己查到的、他人互证的、实物证据。没有"系统告诉你真相"的时刻。
3. **你也在被操控**：游戏前半段让玩家真心相信晴晴，后半段让玩家回头发现"处处是破绽"。
4. **好人难做**：和事佬的本能（息事宁人、讲情面）会被利用。拒绝、对质、报警、保留证据都需要玩家主动选择，并且都有代价。
5. **远方的阴影**：南屿从不出现，却决定一切。

## 3. 基调与参照

- 基调：都市现实主义加慢热悬疑，带黑色幽默（豪车星空顶的"龙"、虹膜取黄金、"下午茶非喝不可"）。
- 情绪曲线：暧昧甜 → 怪异 → 焦虑 → 恐惧 → 冷静 → 怅然。
- 参照作品：《极乐迪斯科》（内心声音、对话即玩法）、《黑色洛城》（审讯）、《Shadows of Doubt》（线索板）、《巫师3》（支线）、《如龙》（都市日常与人情支线）、纪实写作的口吻（每章开场的旁白）。

## 4. 世界：湾城（Bay City）

虚构的美国西海岸大城市，华人社区庞大，灰色地带众多（个人名下租车、私下换汇、无证居留）。

### 4.1 区域地图

| 区域 | 地点 | 主要用途 |
|---|---|---|
| **华埠（Chinatown）** | 老邝租车行、粤式茶餐厅、梅姨风水铺、阿珍直销体验店、二手市场 | 委托中心、流言集散地 |
| **橡树谷（郊区住宅）** | 晴晴的三处租屋（A：三卧独立屋；B：沈曼名下房子，距A五分钟；C：12月新居）、玩家住处（与房客小吴同住） | 主线核心场景 |
| **山景高地** | 豪宅区（8处可看房屋）、物业经纪办公室 | 看房日常 |
| **海滨大道** | 网红餐厅、高档酒店下午茶、海边步道 | 约会与流言 |
| **金融区** | "投行"大楼（同楼有移民律所）、联邦大楼（探员办公室）、法院 | 后期调查 |
| **西岭购物中心** | 奢侈品店、商场 | 消费与人设表演 |
| **运动与社交** | 高尔夫练习场、会员制会所、高端健身房 | 晴晴物色新目标的地方 |
| **警察分局** | 询问室、报案大厅 | 第五幕 |
| **远郊** | 联邦监狱（单程2小时车程）、沙漠赌场度假村、邻市日本城（樱花节） | 长途驾驶段落 |
| **线上世界** | 手机：微信、WhatsApp、电报、小橙书、搜索引擎、法院案件系统、联邦监狱查询网站、银行 App | 信息战场 |

### 4.2 不可到达的地方
- **南屿 / 圣罗莎港**：只存在于聊天记录、卷宗、新闻和晴晴的故事里。
- **伦敦**：只存在于照片和她的讲述里（劳斯莱斯、私人飞机、胶带封窗……）。
- **国内**：只通过电话和微信连接（国内警方、赵慧、小雯、许建国、秦母、许母）。

> 设计意图：玩家活动范围是"安全的"湾城，但所有真正危险的事都发生在玩家去不了的地方。探员那句"这里是美国，不是南屿"在游戏里是一句安慰，也是一种无力。

## 5. 主角：陈默

- 40多岁，在湾城生活20多年，已入籍。早年做投资，风光过，后来失败，正处于低谷，没工作。
- 曾在私家侦探社工作：会查公开记录、会观察，但已经生疏。
- 性格随和，爱当和事佬，"凡事都好商量"。比晴晴大十几岁，对她多一份包容。
- **Want**：重新被需要；一段关系；或许还有那份"月薪5万"的工作。
- **Need**：学会说"不"，学会核实。
- **信念谎言**："凡事都好商量。"
- **内心声音**（《极乐迪斯科》式，按属性触发）：
  - 🟣 **妈妈**："这个女孩子看上去很复杂，你要多了解一下，不要这么急。"（直觉 / 警觉）
  - 🔴 **欲望**："人家才25岁，经历再复杂能有多复杂？"（自我说服）
  - 🟢 **和事佬**："各让一步吧，何必闹僵。"（调解加成，但会让你吃亏）
  - 🔵 **老侦探**："名字、日期、地址。先记下来。"（调查加成）

```
序章  押金          2025.2        调解教学，加微信
第一幕 饵           2025.2–4      赌场工作诱饵 / 千金人设 / 同居 / 纹身 / 妈妈的警告
第二幕 裂           2025.4–7      赌场之行"弄到南屿去" / 看房循环 / 账单泄密 / 被请出门
第三幕 冻           2025.7–11     冻卡 / 28天 / 真名 / 搜索 / 鹿鸣案 / 版本一 / 拉黑
第四幕 卷宗         2025.12       搬家日潜入关卡 / 诈问电话 / 重新调查她的一生
第五幕 反噬         2026.1–4      假报案辩护 / 恐吓 / VAWA 真相 / 探员 / 上门大闹
终幕  第四个版本    2026.4        最后的晚餐：她的新版本，你的选择
尾声  遣返          2026.7–8      按玩家状态生成"结局幻灯片"
```

**分支与瓶颈**：每一幕结尾都是瓶颈（硬节拍必发生），幕内由支线和抉择累积状态。

## 8. 关键状态变量

| 变量 | 含义 | 主要影响 |
|---|---|---|
| `attachment` 依恋（0–100） | 玩家对晴晴的情感投入 | 解锁亲密对话；越高，越容易被"站在我这边"说服 |
| `clarity` 清醒度（0–100） | 玩家识破操控的能力（由证据加反思积累） | 解锁"内心声音：老侦探"；对质选项 |
| `doubt` 自我怀疑（0–100） | 被反问、被否认后积累 | 高时对话选项被"和事佬"或"欲望"覆盖 |
| `cred` 社区可信度 | 华人圈是否相信你 | 证人是否愿意开口 |
| `heat` 麻烦度 | 别人是否怕被你牵连 | 无证人士回避你 |
| `evidence[case]` | 各案证据链完整度 | 结局 |
| `debt_friends` | 朋友损失与你的补偿 | 朋友结局 |
| flags | `married`、`xiaowen_lured`、`opened_suitcase`、`read_phone`、`lied_on_call`、`recorded_dinner`、`warned_eric`…… | 分支 |

## 9. 结局总览（详见 05）

| 结局 | 条件概要 | 基调 |
|---|---|---|
| **E1 和事佬**（原作线） | 未结婚，保留证据但未公开 | 怅然、自保 |
| **E2 档案**（公开） | 三案证据链 ≥ 阈值，交给"青苔档案"或鹿鸣家人 | 沉重的真相 |
| **E3 下一个陈默** | 未警告冯逸，且证据不足 | 循环的悲剧 |
| **E4 VAWA 陷阱**（坏） | 结婚，且在高压事件中动手或被构陷成功 | 牢狱之灾 |
| **E5 共谋**（最坏） | 参与"弄到南屿"或主动参与资金链 | 你成了链条的一环 |
| **E6 回家**（隐藏） | 高清醒度、适度依恋、获得父亲线 | 开放式，不确定她是否登机 |

结局之外还有**结局幻灯片**：根据玩家行为，逐一交代老邝、芳姐、小吴、赵慧、周志强、朋友们、冯逸、阿珍等人的去向（《辐射：新维加斯》式）。

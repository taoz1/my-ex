# 文生图素材清单 · 第一批（序章 + 第一幕）

> 用法：每个素材复制「完整提示词」到 Codex 文生图，生成后按「文件路径」保存到仓库里（路径相对仓库根目录 `my-ex/`）。
> 提示词用英文写（图像模型对英文理解更稳），中文说明供你核对画面。
> 画面里需要出现的文字（纹身句子、收据内容、聊天记录）**不要让模型画**，我会用代码叠加，所以提示词里都写了 "no text"。

## 0. 统一规格（请先看）

### 0.1 风格前缀
所有提示词开头都已经拼好下面这段，保证风格统一：

```
STYLE: 2D pixel art, 16-bit era RPG style, clean pixel clusters, limited warm palette with muted teal shadows, soft evening light, modern-day Chinese-American community setting, realistic proportions, no text, no watermark, no logo.
```

> 这是我提出的默认风格：16-bit 像素风，俯视 3/4 视角，类似《星露谷物语》《去月球》的观感，现代都市现实题材。**如果你想换风格**（比如手绘插画、赛璐璐、更写实），告诉我，我会统一替换风格前缀。

### 0.2 尺寸与格式

| 类型 | 文件夹 | 尺寸 | 背景 | 说明 |
|---|---|---|---|---|
| 对话头像 | `assets/portraits/` | 1024×1024 | **透明** | 胸像，正面略侧，用于对话框 |
| 地图行走图 | `assets/sprites/` | 1024×256 | **透明** | 一张图里4个朝向并排：下、左、右、上 |
| 场景地图 | `assets/maps/` | 1536×1024 | 不透明 | 俯视 3/4 视角，玩家可行走的场景 |
| 物件 / 证据 | `assets/items/` | 1024×1024 | **透明** | 单个物件，用于线索板和背包 |
| 界面 | `assets/ui/` | 见各条 | 见各条 | 线索板、手机、标题画面 |

- 一律保存为 **PNG**。
- 如果 Codex 不支持透明背景，就用**纯品红色背景 #FF00FF**，我会用代码抠掉。
- 同一个角色的头像和行走图，请尽量在同一个会话里连续生成，并上传第一张作为参考图，以保持长相一致。
